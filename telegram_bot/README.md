## 🌟 Полный перечень педагогических функций

1. **Диалог с Совёнком-Методистом AI:**
   * Текстовая консультация на базе YandexGPT Pro с академическим контекстом советских методик (Пчёлко, Костин, Редозубов, Мазина) и ТРИЗ.
   * Автономный эвристический fallback-генератор, если сеть недоступна.

2. **✨ «Улучшить с MetodistPro AI» (`/enhance <тема>`):**
   * Комплексное 6-модульное педагогическое обогащение любого урока:
     1. 🎭 Драматизированный диалог учителя с классом и проблемная ситуация.
     2. ⏱️ Поминутный тайм-план (40 мин по СанПиН).
     3. 🧩 ТРИЗ-задача открытого типа (эвристика).
     4. 🪤 Ловушка Незнайки на типичную ошибку.
     5. 📚 Дифференцированное домашнее задание (3 уровня).
     6. 💬 Готовый пост для родительского чата WhatsApp/TG.

3. **⚡ Кастомные действия и команды учителя (`/addaction`, `/actions`, `/delaction`):**
   * Создание собственных команд: `/addaction <имя> <шаблон промпта>` с поддержкой переменной `{topic}`.
   * Вызов созданного действия напрямую как команды: `/<имя> <тема>` или `/do <имя> <тема>`.
   * Просмотр сохранённых действий: `/actions`.
   * Предустановленные шаблоны: стих/рифмовка к уроку, вопросы для рефлексии, экспресс-карточка на 3 минуты.

4. **💬 Посты для родительских чатов (`/parents <тема>`):**
   * Формирование готового текста для WhatsApp / Telegram классов с похвалой учеников и кратким домашним советом на 5 минут без стресса.

3. **📚 3 Уровня домашнего задания (`/hw <тема>`):**
   * *Уровень 1 (Базовый)*: обязательный тренировочный алгоритм ФГОС на 7–10 мин.
   * *Уровень 2 (Продвинутый)*: примеры с подвохом для соседа по парте.
   * *Уровень 3 (ТРИЗ-вызов)*: олимпиадная эвристическая задача со звёздной наградой.

4. **🎮 Сюжетные квесты и обучающие игры (`/game <тема>`):**
   * 10-минутная динамическая игра по 5 игровым мирам с маскотами (Лисёнок Астро, Совёнок Архип, Енот Шерлок, Бобёр Винтик, Медвежонок Барни).

5. **📝 Экспресс-тесты среза знаний (`/test <тема>`):**
   * 3 быстрых проверочных вопроса с вариантами ответов, эталоном и критериями оценивания (⭐⭐⭐).

6. **📄 Экспресс-рабочие листы (`/worksheet <тема>`):**
   * 3 практических упражнения прямо в сообщении Telegram.

7. **🎭 5 Педагогических ролей (`/modes`):**
   * Академический эксперт, Дипломат родительских чатов, Дифференциатор ДЗ, Игропрактик & Миры, ТРИЗ-наставник.

8. **🤸 Физкультминутка по СанПиН (`/break`):**
   * Потягивания, упражнения на координацию и гимнастика для глаз.

9. **🪤 Ловушка Незнайки (`/trap <тема>`):**
   * Забавное задание с типичной ошибкой для развития критического мышления.

10. **🎙️ Вводное слово учителя (`/intro <тема>`):**
    * Вдохновляющий текст на первые 2 минуты урока для включения 100% внимания детей.

11. **⏰ Утренний дайджест уроков (`/remind`):**
    * Интерактивное расписание на день с напоминанием подготовки листов заданий.

12. **🚀 Telegram Mini App (TMA):**
    * Кнопка «Открыть Методист» в левом нижнем углу чата.
    * Полноэкранный конструктор уроков и 173 готовые темы по ФГОС.
    * Haptic feedback и автоопределение темы (светлая/тёмная).
