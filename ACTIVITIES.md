# Стандарт шаблона практических заданий и педагогических приёмов (Activities Standard)

Документ регламентирует расширенный формат описания дидактических приёмов, динамических пауз, каллиграфических и нейромоторных заданий в приложении **«Методист»**.

---

## 1. Общие принципы

Библиотека приёмов хранится в формате JSON в директории `assets/data/activities.json` и валидируется схемой `assets/data/activities_schema.json` (JSON Schema Draft-07).

Основные цели новой структуры:
- **Структурированность**: разделение сценария на последовательные шаги (`steps`) вместо сырого неструктурированного текста.
- **Тайминг урока**: поле `duration_minutes` позволяет алгоритму составления конспектов точно распределять время урока.
- **Дифференциация**: указание сложности (`difficulty`: `easy`, `medium`, `hard`) и образовательных результатов (`learning_objectives`).
- **Инвентарь**: перечень необходимых материалов (`materials`) для предварительной подготовки педагога.
- **Оценка результатов**: чёткие критерии наблюдения и контроля (`assessment`).
- **Обратная совместимость**: наличие поля `sample_text` и вычисляемого геттера `effectiveSampleText` в моделях Dart.

## 2. Спецификация полей

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `id` | `string` | Да | Уникальный ключ приёма. Формат: `act_<snake_case>` (например, `act_finger_gym`). |
| `category` | `string` | Да | Категория из справочника `categories.json` (например, "Разминка", "Чистописание"). |
| `title` | `string` | Да | Название приёма для UI и заголовков в PDF/конспекте. |
| `short_description` | `string` | Да | Лаконичное описание сути и направленности приёма (1-2 предложения). |
| `duration_minutes` | `integer` | Да | Рекомендуемая продолжительность в минутах (от 1 до 120). |
| `difficulty` | `string` | Да | Уровень сложности: `"easy"`, `"medium"`, `"hard"`. |
| `learning_objectives` | `array[string]` | Да | Список учебных и развивающих целей. |
| `materials` | `array[string]` | Да | Необходимый раздаточный материал, прописи, инвентарь. |
| `steps` | `array[object]` | Да | Массив последовательных шагов (см. структуру шага ниже). |
| `assessment` | `object` | Да | Формат и критерии проверки усвоения. |
| `tags` | `array[string]` | Да | Теги для поиска и категоризации. |
| `metadata` | `object` | Нет | Служебная информация: дата создания/обновления, автор, первоисточник. |
| `sample_text` | `string` | Нет | Текстовая версия для обратной совместимости с legacy-интеграциями. |

### Структура шага (`ActivityStep`)
```json
{
  "order": 1,
  "title": "Упражнение 'Замочек'",
  "description": "Сцепление пальцев в замок, волнообразные движения кистями.",
  "media": ["assets/images/sample.png"] // опционально
}
```

### Структура оценивания (`ActivityAssessment`)
```json
{
  "type": "observation", // "observation" | "test" | "verbal" | "practical" | "rubric"
  "criteria": [
    "Свободные ненапряженные движения",
    "Точное смыкание пальцев"
  ]
}
```

## 3. Пример элемента библиотеки

```json
{
  "id": "act_finger_gym",
  "category": "Разминка",
  "title": "Пальчиковая гимнастика",
  "short_description": "Разогрев кистей, снятие гипертонуса пальцев перед работой.",
  "duration_minutes": 5,
  "difficulty": "easy",
  "learning_objectives": [
    "Разогреть мелкие мышцы кистей и фаланги пальцев",
    "Снять мышечное напряжение и гипертонус перед письменной работой"
  ],
  "materials": [
    "Массажные шарики Су-Джок (по желанию)"
  ],
  "steps": [
    {
      "order": 1,
      "title": "Упражнение 'Замочек'",
      "description": "Сцепление пальцев в замок, мягкие волнообразные движения кистями."
    },
    {
      "order": 2,
      "title": "Упражнение 'Колечки'",
      "description": "Поочерёдное плотное касание большого пальца со всеми остальными."
    }
  ],
  "assessment": {
    "type": "observation",
    "criteria": [
      "Свободные, ненапряженные движения",
      "Точное изолированное смыкание пальцев"
    ]
  },
  "tags": ["разминка", "моторика", "кисти"]
}
```

## 4. Инструменты валидации

Для автоматической проверки структуры перед сборкой и коммитом используется скрипт:

```bash
node scripts/validate_activities.js
```

Также в проекте присутствует тест Dart:
```bash
flutter test test/activities_template_test.dart
```
