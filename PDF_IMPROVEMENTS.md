# Предложения по улучшению генерации PDF

## 1. Проблема с одинаковыми PDF файлами

### Анализ проблемы
При генерации нескольких PDF (конспект, лист заданий, домашняя работа) получаются одинаковые файлы из-за:
- Нечеткого разделения контента по типам материалов
- Отсутствия явных маркеров разделов в генерируемом контенте

### Решения:
1. **Улучшить метод `_extractMaterialContent`** в `pdf_export_service.dart`:
   - Добавить более точное определение границ разделов
   - Использовать ключевые слова: "РАБОЧИЙ ЛИСТ", "ДОМАШНЯЯ РАБОТА", "РАЗДАТОЧНЫЕ КАРТОЧКИ"

2. **Добавить явные маркеры в генерацию контента**:
   - При генерации контента AI добавлять четкие разделители
   - Использовать специальные комментарии или заголовки

3. **Улучшить логику `_splitContentBySections`**:
   - Добавить поддержку различных форматов заголовков
   - Учитывать вложенность разделов

## 2. Проблема с H1 вместо заголовков

### Анализ проблемы
В контенте могут присутствовать HTML-теги `<h1>`, `<h2>` вместо Markdown `# `, `## `.

### Решения:
1. **Добавлена функция `_cleanHtmlTags`** для преобразования HTML в Markdown
2. **Обработка различных форматов заголовков**:
   - HTML теги: `<h1>`, `<h2>`, `<h3>`
   - Markdown: `# `, `## `, `### `
   - Прочие форматы

## 8. Примеры кода для реализации

### 8.1 Улучшенный метод разделения контента:
```dart
static Map<String, String> _splitContentBySectionsEnhanced(String content) {
  final sections = <String, String>{};
  final lines = content.split('\n');
  
  String? currentSection;
  final sectionContent = StringBuffer();
  
  // Регулярные выражения для разных форматов заголовков
  final headerPatterns = [
    RegExp(r'^#{1,4}\s+(.+)$'),                    // Markdown #, ##, ###, ####
    RegExp(r'^(?:\d+[\.\)]\s*)?([A-ZА-Я][^\.:]+)[\.:]?\s*$'), // Нумерованные заголовки
    RegExp(r'^([A-ZА-Я][^\.:]{5,})[\.:]?\s*$'),    // Заголовки в верхнем регистре
  ];
  
  for (final line in lines) {
    final trimmed = line.trim();
    bool isHeader = false;
    String? headerText;
    
    // Проверяем все форматы заголовков
    for (final pattern in headerPatterns) {
      final match = pattern.firstMatch(trimmed);
      if (match != null) {
        isHeader = true;
        headerText = match.group(1)!.trim();
        break;
      }
    }
    
    if (isHeader && headerText != null) {
      // Сохраняем предыдущий раздел
      if (currentSection != null && sectionContent.isNotEmpty) {
        sections[currentSection] = sectionContent.toString().trim();
        sectionContent.clear();
      }
      currentSection = headerText;
    } else if (currentSection != null) {
      sectionContent.writeln(line);
    }
  }
  
  // Сохраняем последний раздел
  if (currentSection != null && sectionContent.isNotEmpty) {
    sections[currentSection] = sectionContent.toString().trim();
  }
  
  return sections;
}
```

### 8.2 Улучшенный метод извлечения материала:
```dart
static String _extractMaterialContentEnhanced(String content, PdfMaterialType type) {
  final sections = _splitContentBySectionsEnhanced(content);
  
  // Ключевые слова для каждого типа материала
  final Map<PdfMaterialType, List<String>> keywords = {
    PdfMaterialType.conspect: [
      'цель', 'задачи', 'ход занятия', 'организационный момент',
      'основная часть', 'заключение', 'рефлексия'
    ],
    PdfMaterialType.worksheet: [
      'рабочий лист', 'лист заданий', 'раздаточный материал',
      'упражнения', 'задания для работы'
    ],
    PdfMaterialType.homework: [
      'домашняя работа', 'задание на дом', 'дополнительные задания',
      'для самостоятельной работы'
    ],
  };
  
  // Поиск подходящих разделов
  final relevantSections = <String, String>{};
  final typeKeywords = keywords[type] ?? [];
  
  for (final entry in sections.entries) {
    final sectionTitle = entry.key.toLowerCase();
    final sectionContent = entry.value;
    
    // Проверяем ключевые слова в заголовке
    bool isRelevant = typeKeywords.any((keyword) => 
        sectionTitle.contains(keyword));
    
    // Проверяем ключевые слова в содержимом (первые 200 символов)
    if (!isRelevant && sectionContent.length > 50) {
      final preview = sectionContent.substring(0, 200).toLowerCase();
      isRelevant = typeKeywords.any((keyword) => preview.contains(keyword));
    }
    
    if (isRelevant) {
      relevantSections[entry.key] = entry.value;
    }
  }
  
  // Собираем результат
  if (relevantSections.isEmpty) {
    // Если не нашли подходящих разделов, возвращаем весь контент
    return content;
  }
  
  return relevantSections.entries
      .map((entry) => '# ${entry.key}\n${entry.value}')
      .join('\n\n');
}
```
