# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — поются,
Согласные — как будто гремят.
Слог ударный выделяем,
Ударение правильно ставим.

#### Ловушка для внимательных:
Некоторые дети думают, что все буквы, которые обозначают звуки, можно разделить только на гласные и согласные. Но есть ещё и буквы, которые не обозначают звуков! Попробуй найти такие буквы в словах и объясни, для чего они нужны.

#### Уровень 1: Старт

Задание 1: образец решения

Соедините звуки с их характеристиками:
Звуки: [м], [о], [п], [ы]
Характеристики: гласный, согласный

Задание 3: раскраска
Раскрасьте гласные звуки красным цветом, а согласные — синим: [л], [э], [р], [ю].

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Заполните таблицу, распределив слова по количеству слогов:
| 1 слог | 2 слога | 3 слога |
| --- | --- | --- |
|   |   |   |
Слова для распределения: дом, лес, школа, книга, машина, поезд.

Задание 5: ловушка Незнайки
Незнайка утверждает: «В слове «стол» два слога». Найди ошибку Незнайки и запиши правильное объяснение:
Линии для ответа: _______________________

Задание 6: каллиграфическая минутка / прописи
Напишите слоги, используя образные элементы букв Мазиной: ма, му, ми, мо.
Линии для ответа: _______________________

#### Уровень 3: Детектив Pro

Задание 7: шифровка

Кодовая таблица: 1=А, 2=Р, 3=Т, 4=И
Линии для ответа: _______________________

Задание 8: логическая ТРИЗ-задача
В каком слове больше слогов: «сосна» или «ель»? Объясни свой ответ:
Линии для ответа: _______________________
