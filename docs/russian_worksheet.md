# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся, как песня, — можем мы их пропеть.
Согласные — как марш, строги и кратки, в них нет тянучки.

#### Ловушка для внимательных:
Часто дети думают, что все буквы, которые стоят в начале слова, — согласные. Но это не так! Например, в слове «яма» первая буква «я» — гласная, потому что мы можем её пропеть.

#### Уровень 1: Старт

Задание 1: образец решения
Напиши, гласный или согласный звук в каждом слове выделен:
- п**е**ро — гласный;
- с**т**ол — _______________________;
- **в**олк — _______________________;
- р**ы**ба — _______________________;
- **м**ягкий — _______________________.

Задание 2: соедини стрелками
Соедини слова с их характеристиками:
| Слова | Характеристики |
| --- | --- |
| к**о**т | гласный звук |
| **д**ом | согласный звук |
| п**и**р | гласный звук |
| **л**ев | согласный звук |

Задание 3: раскраска
Раскрась гласные звуки красным, а согласные — синим:
- **с**о**л**н**ц**е;
- **п**а**р**т**а**;
- **я**бл**о**к**о**;
- **з**е**м**л**я**.

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распредели слова в таблицу:
| Гласные | Согласные |
| --- | --- |
| | |
| | |

Слова для распределения: солнце, парта, яблоко, земля, дом, кот.

Задание 5: ловушка Незнайки
Незнайка утверждает: «В слове «ёж» первый звук гласный». Найди ошибку Незнайки и запиши правильное объяснение:
Линии для ответа: ____________________________________________________

Задание 6: каллиграфическая минутка / прописи
Пропиши элементы букв по образцу:
- качалочка;
- секретик;
- крючок до середины строки.

Слоги для прописывания: ма, му, мы, ми.

#### Уровень 3: Детектив Pro

1=А, 2=Р, 3=Т, 4=И, 5=С

Линии для ответа: _______________________

Задание 8: логическая ТРИЗ-задача
Найди слово, в котором первый слог состоит только из согласных звуков:
- стол;
- книга;
- шкаф;
- дверь.
Линии для ответа: _______________________
