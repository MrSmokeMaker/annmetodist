# Лист заданий для печати

## Главное правило урока:
Гласные тянутся — песенки поют,
Согласные — шаги: топ-топ-топ идут!

## Ловушка для внимательных:
Часто дети думают, что если буква «й» стоит в конце слова, то она гласная. Но это не так! «Й» — всегда согласный звук, даже если он стоит в конце слова.

### Уровень 1: Старт

**Задание 1: образец решения**

Распредели буквы на гласные и согласные:

Образец: а — гласная, потому что её можно пропеть.

1. м — ____________________________________________________
2. у — ____________________________________________________
3. к — ____________________________________________________
4. и — ____________________________________________________

**Задание 2: соедини стрелками**

Соедини буквы с их характеристиками:

| Буквы | Характеристики |
| --- | --- |
| а | гласный |
| б | согласный |
| у | гласный |
| д | согласный |

**Задание 3: раскраска**

Раскрась гласные красным, а согласные синим:

м, а, к, и, б, у, д, ы

### Уровень 2: Практик

**Задание 4: сортировочная таблица**

Распредели слова в таблицу:

| Гласные | Согласные |
| --- | --- |
| | |

Слова для распределения: мама, дом, мяч, книга, луна, сад.

**Задание 5: ловушка Незнайки**

Незнайка утверждает: «Буква «й» — гласная, потому что она стоит в конце слова «май»». Найди ошибку Незнайки и запиши правильное объяснение:

Линии для ответа: __________________________________________

**Задание 6: каллиграфическая минутка**

Пропиши элементы букв по образцу:

качалочка, секретик, крючок до середины строки

### Уровень 3: Детектив Pro

**Задание 7: шифровка**

Разгадай зашифрованное слово:

1 = А, 2 = Р, 3 = Т, 4 = И, 5 = С

Зашифрованное слово: 5-4-3-1

**Задание 8: логическая ТРИЗ-задача**

Какое слово состоит из трёх слогов, начинается на гласный и заканчивается на согласный?

Линии для ответа: __________________________________________
