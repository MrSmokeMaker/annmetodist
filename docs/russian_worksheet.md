# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — песенки поют,
Согласные — как марш: раз-два-три идут!

#### Ловушка для внимательных:
Почему Незнайка думает, что в слове «крот» три согласных подряд?
Найди ошибку Незнайки и запиши правильное объяснение:
Линии для ответа: _______________________

#### Уровень 1: Старт

Задание 1: образец решения
Напиши, какие звуки в каждом слове: гласные или согласные.
Образец: кот — [к], [о], [т] — все согласные, кроме [о].
Слова для задания: дом, лес, мяч.

Задание 2: соедини стрелками
Соедини слова с их характеристиками:
Слова: мак, сыр, жук.
Характеристики: один гласный звук, два согласных звука, три согласных звука.

Задание 3: раскраска
Раскрась гласные красным, а согласные синим:
Слова: рак, кит, лес.

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распредели слова в таблицу по количеству гласных звуков:
| Один гласный | Два гласных |
| --- | --- |
|   |   |
Слова для распределения: дом, лес, мяч, роза, луна.

Задание 5: Ловушка Незнайки
Незнайка утверждает: «В слове «крот» три согласных звука подряд!»
Найди ошибку Незнайки и запиши правильное объяснение:
Линии для ответа: _______________________

Задание 6: каллиграфическая минутка
Пропиши элементы букв Мазиной: качалочка, секретик, крючок до середины строки.
Затем пропиши слоги: ма-му-мы, ра-ру-ры.

#### Уровень 3: Детектив Pro

Задание 7: шифровка
Разгадай зашифрованное слово:
Кодовая таблица: 1=А, 2=Р, 3=Т, 4=И, 5=С
Зашифрованное слово: 2-4-3-1
Разгаданное слово: _______________________

Задание 8: логическая ТРИЗ-задача
Какое слово содержит больше звуков — «лес» или «лиса»? Объясни свой ответ:
Линии для ответа: _______________________

#### Самооценка и рефлексия
⭐⭐⭐ Оцени свои успехи на занятии:
1. Я умею различать гласные и согласные звуки. ⭐⭐⭐
2. Я могу правильно определять количество гласных и согласных звуков в словах. ⭐⭐⭐
3. Я научился прописывать элементы букв Мазиной. ⭐⭐⭐
