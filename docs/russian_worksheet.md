# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — звонкие, долгие,
Согласные — как стук, как шорох в поле.

#### Ловушка для внимательных:
Некоторые дети думают, что буквы «й», «ч», «щ» — гласные, потому что при их произнесении голос не «стучит», а звучит мягко. На самом деле эти буквы — согласные, потому что они не образуют слога сами по себе.

#### Уровень 1: Старт

Задание 1: образец решения
Распределите буквы на гласные и согласные:
- Гласные: а, о, у, э, ы, и, е, ё, ю, я.
- Согласные: все остальные буквы.
Образец: а — гласная, б — согласная.
Теперь попробуйте сами:
1. О — ______, п — ______.
2. У — ______, р — ______.
3. Э — ______, с — ______.

Задание 2: соедини стрелками
Соедините звуки с их характеристиками:
| Звук | Характеристика |
| --- | --- |
| [а] | гласный |
| [б] | согласный |
| [у] | гласный |
| [в] | согласный |

Задание 3: раскраска
Раскрасьте гласные звуки красным цветом, а согласные — синим:
- А, б, у, в, э, г, ы, д, и, ж.

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распределите слова по колонкам в зависимости от количества слогов:
| 1 слог | 2 слога | 3 слога |
| --- | --- | --- |
| дом | вода | машина |
| кот | книга | карандаш |
Слова для распределения: дом, вода, машина, кот, книга, карандаш.

Задание 5: Ловушка Незнайки
Незнайка утверждает: «В слове «стол» два слога». Найдите ошибку Незнайки и запишите правильное объяснение:
Линии для ответа: _______________________

Задание 6: каллиграфическая минутка / прописи
Напишите слоги, используя образные элементы букв (по методике Мазиной):
- Качалочка: ма, му, мы.
- Секретик: ра, ру, ры.
- Крючок до середины строки: ла, лу, лы.

#### Уровень 3: Детектив Pro

Задание 7: настоящая шифровка
Разгадайте зашифрованное слово:
1 = А, 2 = Р, 3 = Т, 4 = И, 5 = С
Зашифрованное слово: 5-4-3-1

Задание 8: логическая ТРИЗ-задача
Найдите слово, которое подходит под все три характеристики:
- Состоит из трёх слогов.
- Начинается на гласную букву.
- Заканчивается на согласную букву.
Линии для ответа: _______________________
