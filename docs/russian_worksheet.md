# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — звонко поют, 
Согласные — звуки других, не поют, а говорят.

#### Ловушка для внимательных:
Ловушка: «Звук [й’] — согласный, потому что он не тянется». 
Ошибка: звук [й’] действительно не тянется, но он звонкий и поётся, как гласный. 
Правильно: [й’] — согласный звук, потому что он звонкий, но при этом не тянется.

#### Уровень 1: Старт

Задание 1: образец решения
Определи, гласный или согласный звук в каждом слове, и объясни почему.
Образец: слово «дом» — первый звук [д] согласный, потому что он не поётся и не тянется.
Слова: лес, яма, рот.

Задание 2: соедини стрелками
Соедини звуки с их характеристиками:
| Звуки | Характеристики |
| --- | --- |
| [а] | гласный, поётся, тянется |
| [б] | согласный, не поётся, не тянется |
| [у] | гласный, поётся, тянется |
| [в] | согласный, не поётся, не тянется |

Задание 3: раскраска
Раскрась гласные звуки красным, а согласные — синим:
Слова: мак, кит, лес.

#### Уровень 2: Практик

Слова для распределения: яма, дом, лес, оса.

Слоги для прописывания: ма, му, мы.
Линии для ответа: _______________________
