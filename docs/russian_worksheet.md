# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — песенки поют,
Согласные — в шалашах стоят и сторожат.

#### Ловушка для внимательных:
Типичная ошибка: дети часто путают звуки [й’] и [и].
Совет-подсказка: звук [й’] — согласный, его можно сравнить с ёжиком, который пробирается сквозь заросли, а [и] — гласный, его можно протянуть, как песню.

#### Уровень 1: Старт

Задание 1: образец решения
Определи, гласные или согласные звуки в словах:
1. Солнце — [с] — согласный, потому что нельзя протянуть.
2. Апельсин — [а] — гласный, потому что можно протянуть.
3. Дом — [д] — _______________________
4. Ёжик — [й’] — _______________________

Задание 2: соедини стрелками
Соедини звуки с их характеристиками:
| Звуки | Характеристики |
| --- | --- |
| [м] | Гласный |
| [о] | Согласный |
| [р] | Согласный |
| [у] | Гласный |

Задание 3: раскраска
Раскрась гласные красным, а согласные синим:
* лес;
* дом;
* мяч;
* роза.

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распредели слова в таблицу:
| Гласные | Согласные |
| --- | --- |
| | |
| | |

Слова для распределения: лес, дом, мяч, роза, окно, стол.

Задание 5: ловушка Незнайки
Незнайка утверждает: «В слове „стол“ все звуки гласные».
Найди ошибку Незнайки и запиши правильное объяснение:
Линии для ответа: _______________________

Задание 6: каллиграфическая минутка
Пропиши элементы букв по образцу:
* качалочка;
* секретик;
* крючок до середины строки.

Слоги для прописывания: ма, му, мы, мо.

#### Уровень 3: Детектив Pro

Задание 7: шифровка
Разгадай зашифрованное слово:
Кодовая таблица: 1=А, 2=Р, 3=Т, 4=И, 5=С
Зашифрованное слово: 4-3-1

Задание 8: логическая задача
Какое слово содержит больше звуков: «лес» или «стол»? Объясни свой ответ:
Линии для ответа: _______________________

#### Самооценка и рефлексия
⭐⭐⭐ Оцени свои успехи на занятии:
1. Я умею различать гласные и согласные звуки. ⭐⭐⭐
2. Я могу правильно определять количество звуков в слове. ⭐⭐⭐
3. Я научился прописывать элементы букв. ⭐⭐⭐
