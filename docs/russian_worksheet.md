# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — песенки поют,
Согласные — в гости к ним идут.

#### Ловушка для внимательных:
Типичная ошибка: дети часто путают звуки и буквы.
Совет-подсказка: звуки мы слышим и произносим, а буквы видим и пишем.

#### Уровень 1: Старт

Задание 1: образец решения
Напиши, какой звук в каждом слове первый: гласный или согласный.
Образец: дом — первый звук согласный, потому что мы не можем его тянуть.
Слова: яма, кот, ель, рак.

Задание 2: соедини стрелками
Соедини слова с их характеристиками:
| Слова | Характеристики |
| --- | --- |
| лес | первый звук гласный |
| ива | первый звук согласный |
| мёд | последний звук гласный |
| жук | последний звук согласный |

Задание 3: раскраска
Раскрась гласные звуки красным, а согласные — синим.
Слова: шар, сыр, кит, сом.

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распредели слова в таблицу по количеству слогов:
| 1 слог | 2 слога | 3 слога |
| --- | --- | --- |
|   |   |   |

Слова для распределения: дом, лес, мяч, слон, кошка, собака, машина.

Задание 5: ловушка Незнайки
Незнайка утверждает: «В слове «школа» три слога». Найди ошибку Незнайки и запиши правильное объяснение.
Линии для ответа: _______________________

Задание 6: каллиграфическая минутка / прописи
Пропиши элементы букв Мазиной: качалочка, секретик, крючок до середины строки. Затем пропиши слоги: ма, му, мы.
Линии для ответа: _______________________

#### Уровень 3: Детектив Pro

Задание 7: шифровка
Разгадай зашифрованное слово: 1-2-3-4.
Кодовая таблица:
| Число | Буква |
| --- | --- |
| 1 | М |
| 2 | А |
| 3 | К |
| 4 | И |

Задание 8: логическая ТРИЗ-задача
В слове «книга» переставь буквы так, чтобы получилось новое слово. Запиши его.
Линии для ответа: _______________________

#### Самооценка и рефлексия
⭐⭐⭐ Оцени свои успехи на занятии:
1. Я умею отличать гласные звуки от согласных. ⭐⭐⭐
2. Я могу определять количество слогов в слове. ⭐⭐⭐
3. Я знаю, как правильно прописывать элементы букв. ⭐⭐⭐
