# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — поются,
Согласные — как стук дождя.
Слог — как домик для звуков,
Ударение — где голос сильней!

#### Ловушка для внимательных:
Ловушка: «Все звуки, которые нельзя петь — согласные».
Пример ошибки: «Л — согласный, потому что его нельзя петь».
Линии для ответа: _______________________
Правильный ответ: «Л — согласный, но его можно тянуть (например, «л-л-л»), просто он не гласный».

#### Уровень 1: Старт

Задание 1: Соедини стрелками звуки с их характеристиками.

Звуки: А, Л, О, М
Характеристики: гласный, согласный, гласный, согласный

Образец: А — гласный, потому что его можно тянуть.

Задание 2: Раскрась гласные красным, а согласные синим.
Слова: дом, лес, мяч, роза

#### Уровень 2: Практик

Задание 3: Сортировочная таблица. Распредели слова по колонкам в зависимости от количества слогов.

| 1 слог | 2 слога | 3 слога |
| --- | --- | --- |
|   |   |   |

Слова для распределения: дом, лес, мяч, роза, дерево, трава, радуга.

Задание 4: «Ловушка Незнайки».
Незнайка утверждает: «В слове "трава" ударение на первом слоге».
Найди ошибку Незнайки и запиши правильное объяснение: _______________________

Задание 5: Каллиграфическая минутка / прописи.
Пропиши элементы букв Мазиной и слоги: «качалочка», «секретик», «крючок до середины строки», «шалашик».
Линии для ответа: _______________________

#### Уровень 3: Детектив Pro

Задание 6: Шифровка.
Разгадай зашифрованное слово: 1-2-3-4
Кодовая таблица: 1=А, 2=Р, 3=Т, 4=И
Разгаданное слово: _______________________

Задание 7: Логическая ТРИЗ-задача.
Какое слово содержит больше звуков: «лес» или «трава»? Объясни свой ответ: _______________________

#### Самооценка и рефлексия

⭐⭐⭐ Оцени свои успехи на занятии:
1. Умею различать гласные и согласные звуки. ⭐⭐⭐
2. Могу определять количество слогов в слове. ⭐⭐⭐
3. Знаю, как правильно ставить ударение. ⭐⭐⭐
