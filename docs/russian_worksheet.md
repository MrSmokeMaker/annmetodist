# Лист заданий для печати

#### Главное правило урока:
Гласные звуки поются голосом и тянутся, как песенка [а-а-а], во рту нет преград.
Согласные звуки встречают преграду — губы, зубы или язычок [б, п, м, с].
Сколько в слове гласных — столько и слогов!

#### Ловушка для внимательных:
Не путай звуки и буквы! Звуки мы слышим и произносим (пишем в скобках [а]), а буквы — видим, называем и пишем в тетради («а»). Например, звук [м] — согласный твёрдый, а буква называется «эм».

#### Уровень 1: Старт

Задание 1: образец решения
Определи, какой буквой записан гласный звук, а какой — согласный:
Образец: Буква «а» — гласный звук (поётся), буква «б» — согласный звук (губы смыкаются).
Впиши в пропуски слова «гласный» или «согласный»:
1. Буква «о» — ____________ звук, буква «п» — ____________ звук.
2. Буква «у» — ____________ звук, буква «р» — ____________ звук.
3. Буква «э» — ____________ звук, буква «с» — ____________ звук.

Задание 2: соедини стрелками
Соедини аккуратными цветными стрелочками звук и его точную характеристику:
- Звук [а]    •    • Согласный твёрдый звук
- Звук [м]    •    • Гласный звук
- Звук [у]    •    • Согласный мягкий звук
- Звук [к']   •    • Гласный звук

Задание 3: раскраска карточек
Найди гласные и согласные буквы. Карточки с гласными буквами раскрась красным цветом, а с согласными — синим:
[ А ]   [ Б ]   [ У ]   [ М ]   [ О ]   [ К ]   [ Ы ]   [ Д ]   [ И ]   [ Т ]

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распредели слова из корзинки по колонкам в зависимости от количества слогов (прохлопай в ладоши!):
| 1 слог | 2 слога | 3 слога |
| --- | --- | --- |
|        |         |         |
|        |         |         |
|        |         |         |

Слова для распределения: дом, во-да, ма-ши-на, кот, кни-га, ка-ран-даш, шар, ли-са.

Задание 5: Ловушка Незнайки
Незнайка с гордостью сказал: «В слове СТОЛ целых два слога, потому что оно длинное и стол большой!»
Найди ошибку Незнайки, вспомни главное правило урока и запиши правильный ответ:
Линии для ответа: _______________________
Линии для ответа: _______________________

Задание 6: каллиграфическая минутка / прописи
Пропиши по образцу элементы букв и слоги с правильным наклоном 65° (по методике В. Д. Мазиной):
- Элемент «качалочка» (мягкое покачивание внизу строки):  м_а   м_у   м_ы
- Элемент «секретик» (наклонная параллельная линия):      р_а   р_у   р_ы
- Элемент «крючок до середины строки»:                    л_а   л_у   л_ы

#### Уровень 3: Детектив Pro

Задание 7: настоящая шифровка
Шпион зашифровал важное слово с помощью кодовой таблицы. Используй ключ и расшифруй секретное слово:
Кодовая таблица: [ 1 = А ]  [ 2 = И ]  [ 3 = С ]  [ 4 = Т ]
Зашифрованный шифр: 1 - 2 - 3 - 4
Какое слово получилось? Запиши ответ: _______________________

Задание 8: логическая ТРИЗ-задача
Найди среди предложенных слов то единственное слово-загадку, которое подходит сразу под все три условия:
1. В слове ровно три слога.
2. Начинается на гласный звук.
3. Заканчивается на согласный твёрдый звук.
Слова для проверки: а-ист, о-гу-рец, ма-ши-на, ав-то-бус.
Запиши разгаданное слово и докажи свой выбор:
Линии для ответа: _______________________

#### Самооценка и рефлексия
⭐⭐⭐ Оцени свои успехи на занятии:
- Я легко отличаю гласные звуки от согласных.
- Я умею делить слова на слоги по количеству гласных.
- Я старался писать аккуратно и красиво по косой линейке.

#### 🔑 Ключи и ответы для учителя

Задание 1:
1. «о» — гласный, «п» — согласный.
2. «у» — гласный, «р» — согласный.
3. «э» — гласный, «с» — согласный.

Задание 2:
- [а] -> Гласный звук
- [м] -> Согласный твёрдый звук
- [у] -> Гласный звук
- [к'] -> Согласный мягкий звук

Задание 3:
- Красные (гласные): А, У, О, Ы, И.
- Синие (согласные): Б, М, К, Д, Т.

Задание 4:
- 1 слог: дом, кот, шар.
- 2 слога: во-да, кни-га, ли-са.
- 3 слога: ма-ши-на, ка-ран-даш.

Задание 5:
В слове «стол» всего одна гласная («о»), поэтому в нём ровно один слог: [стол]. Длина предмета не влияет на количество слогов!

Задание 6:
Каллиграфически верное безотрывное соединение элементов букв: ма, му, мы; ра, ру, ры; ла, лу, лы с соблюдением наклона 65°.

Задание 7:
Слово: АИСТ (1 - А, 2 - И, 3 - С, 4 - Т).

Задание 8:
Слово: ОГУРЕЦ (3 слога: о-гу-рец; начинается на гласный [о], заканчивается на согласный твёрдый [ц]). Также подходит АВТОБУС (ав-то-бус). Любое из этих слов верно!
