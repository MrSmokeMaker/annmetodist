# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — песенки поют,
Согласные — в гости к ним идут.

#### Ловушка для внимательных:
Некоторые дети думают, что если буква «й» обозначает всегда мягкий согласный звук, то она гласная. Но это не так! Гласные звуки всегда образуют слог, а согласные — нет.

#### Уровень 1: Старт

Задание 1: образец решения
Определи, гласный или согласный звук в каждом слове.
Образец: солнце — первый звук [с] — согласный, потому что он не тянется и не образует слог сам по себе.
Слова для работы: луна, дом, мяч, окно.

Задание 2: соедини стрелками
Соедини звуки с их характеристиками:
* [а] — гласный;
* [б] — согласный;
* [у] — гласный;
* [д] — согласный.

Задание 3: раскраска
Раскрась гласные звуки красным, а согласные — синим.
Слова для работы: лес, дом, мяч, окно, луна.

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распредели слова в таблицу по первым звукам: гласные и согласные.
| Гласные | Согласные |
| --- | --- |
| | |
Слова для распределения: астра, дом, ель, книга, яблоко.

Задание 5: ловушка Незнайки
Незнайка утверждает: «В слове «ёж» первый звук гласный». Найди ошибку Незнайки и запиши правильное объяснение:
Линии для ответа: _______________________

Задание 6: каллиграфическая минутка / прописи
Пропиши элементы букв по методике Мазиной: качалочка, секретик, крючок до середины строки.
Слоги для прописывания: ма, му, мы, ми.

#### Уровень 3: Детектив Pro

Задание 7: шифровка
Разгадай зашифрованное слово: 1-2-3-4.
Кодовая таблица: 1=А, 2=Р, 3=Т, 4=И.
Разгаданное слово: _______________________

Задание 8: логическая ТРИЗ-задача
В каком слове больше звуков: «лес» или «ель»? Объясни свой ответ:
Линии для ответа: _______________________

#### Самооценка и рефлексия
⭐⭐⭐ Оцени свои успехи на занятии:
1. Я умею отличать гласные звуки от согласных. ⭐⭐⭐
2. Я могу правильно определять количество звуков в слове. ⭐⭐⭐
3. Я научился аккуратно писать элементы букв. ⭐⭐⭐
