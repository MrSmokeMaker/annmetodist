# Лист заданий для печати

#### Главное правило урока:
Гласные звуки тянутся, песенки поют, а согласные — солдатики, строй держат, не поют.

#### Ловушка для внимательных:
Почему звук [й’] иногда считают гласным, ведь он не тянется? Потому что он звонкий и поётся, как гласный, но на самом деле он согласный, потому что не может образовать слог сам по себе.

#### Уровень 1: Старт

Задание 1: образец решения

Распределите звуки на гласные и согласные, раскрасьте их красным (гласные) и синим (согласные):

- [а] — красный
- [б] — синий
- [о] — красный
- [п] — синий

Задание 2: соедини стрелками

Соедините звуки с их характеристиками:

Звуки:
- [м]
- [у]
- [к]
- [и]

Характеристики:
- гласный
- согласный
- звонкий
- глухой

Задание 3: раскраска

Раскрасьте гласные звуки красным, а согласные — синим:

Слова:
- дом
- мяч
- лиса
- слон

#### Уровень 2: Практик

Задание 4: сортировочная таблица

Распределите слова в таблицу по количеству слогов:

| 1 слог | 2 слога | 3 слога |
|--------|---------|---------|
|        |         |         |
|        |         |         |

Слова для распределения: дом, лес, слон, лиса, медведь, сорока, ворона.

Задание 5: ловушка Незнайки

Незнайка утверждает: «В слове «школа» три слога». Найдите ошибку Незнайки и запишите правильное объяснение:

Линии для ответа: _______________________

Задание 6: каллиграфическая минутка / прописи

Напишите слоги, используя образные элементы букв по методике Мазиной:

Слоги: ма, му, ми, мо, мы

#### Уровень 3: Детектив Pro

Задание 7: шифровка

Разгадайте зашифрованное слово:

Кодовая таблица:
1 = А, 2 = Р, 3 = Т, 4 = И, 5 = С

Зашифрованное слово: 5-4-3-1

Задание 8: логическая ТРИЗ-задача

Какое слово содержит больше звуков: «ёж» или «юла»? Объясните почему:

Линии для ответа: _______________________

#### Самооценка и рефлексия

⭐⭐⭐ Оцени свои успехи на занятии:

1. Я умею различать гласные и согласные звуки. ⭐⭐⭐
2. Я могу определять количество слогов в слове. ⭐⭐⭐
3. Я знаю, как правильно писать слоги по методике Мазиной. ⭐⭐⭐
