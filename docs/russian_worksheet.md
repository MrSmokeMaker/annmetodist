# Лист заданий для печати

#### Главное правило урока:

Гласные тянутся, как песня,
Согласные — как стук дождя.
Слог — это шаг, а ударение —
Удар в барабан, друзья!

#### Ловушка для внимательных:

Некоторые дети думают, что все звуки, которые произносятся твёрдо, — согласные. Но это не так! Например, звук [о] — гласный, даже если он произносится твёрдо.

#### Уровень 1: Старт

Задание 1: образец решения

Напиши, какой звук произносит каждый зверёк: гласный или согласный.

1. Сова: «У-у-у!» — гласный.
2. Волк: «В-в-в!» — _______________________.
3. Тигр: «Р-р-р!» — _______________________.
4. Утка: «К-к-к!» — _______________________.
5. Корова: «М-м-м!» — _______________________.

Задание 2: соедини стрелками

Соедини звук с его описанием.

Звуки: | Описание:
---|---
[а] | гласный
[б] | согласный
[и] | гласный
[д] | согласный
[о] | гласный

Задание 3: раскраска

Раскрась гласные звуки красным, а согласные — синим.

[а], [б], [и], [д], [о], [п], [у], [ф], [э], [х]

#### Уровень 2: Практик

Задание 4: сортировочная таблица

Распредели слова по колонкам.

| Гласные | Согласные |
| --- | --- |
|   |   |
|   |   |
|   |   |

Слова для распределения: дом, лес, стол, стул, мяч, ключ, гриб, лист.

Задание 5: ловушка Незнайки

Незнайка утверждает, что в слове «стол» три слога. Найди ошибку Незнайки и запиши правильное объяснение.

Линии для ответа: __________________________________________________

Задание 6: каллиграфическая минутка / прописи

Пропиши элементы букв по образцу.

Образец: качалочка, секретик, крючок до середины строки.

Слоги для прописывания: ма, му, мы, ми, мо.

#### Уровень 3: Детектив Pro

Задание 7: шифровка

Разгадай зашифрованное слово.

Кодовая таблица:

1 = А
2 = Б
3 = В
4 = Г
5 = Д

Зашифрованное слово: 1-4-3-2

Разгаданное слово: _____________________

Задание 8: логическая ТРИЗ-задача

Какое слово состоит из трёх слогов и имеет ударение на первом слоге?
