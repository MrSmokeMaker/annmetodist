# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — поются,
Согласные — как будто гремят.
Слог — это дом для звуков,
Ударение — удар в барабан!

#### Ловушка для внимательных:
Ловушка: «Все звуки, которые произносятся с голосом, — гласные».

Объяснение: не все звуки, которые произносятся с голосом, являются гласными. Например, звук [р] — согласный, хотя и произносится с голосом.

#### Уровень 1: Старт

Задание 1: образец решения

Распредели звуки на гласные и согласные:

Образец: [а] — гласный, потому что его можно тянуть и петь.

Звуки: [м], [о], [т], [у], [к], [и].

Задание 2: соедини стрелками

Соедини звуки с их характеристиками:

| Звуки | Характеристики |
| --- | --- |
| [а] | гласный |
| [б] | согласный |
| [и] | гласный |
| [д] | согласный |

Задание 3: раскраска

Раскрась гласные звуки красным, а согласные — синим:

Слова: мама, дом, игра, кот.

#### Уровень 2: Практик

Задание 4: сортировочная таблица

Распредели слова в таблицу по количеству слогов:

| 1 слог | 2 слога | 3 слога |
| --- | --- | --- |
|   |   |   |

Слова для распределения: дом, мама, книга, яблоко, машина, дерево.

Задание 5: ловушка Незнайки

Незнайка утверждает: «В слове "дом" два слога».

Найди ошибку Незнайки и запиши правильное объяснение:

Линии для ответа: _______________________

Задание 6: каллиграфическая минутка / прописи

Пропиши элементы букв по образцу:

Образец: качалочка, секретик, крючок до середины строки.

Слоги для прописывания: ма, му, мы, ми.

#### Уровень 3: Детектив Pro

Задание 7: шифровка

Разгадай зашифрованное слово:

Кодовая таблица:

| Буква | Число |
| --- | --- |
| А | 1 |
| Б | 2 |
| В | 3 |
| Г | 4 |

Зашифрованное слово: 2-1-3

Разгаданное слово: _______________________

Задание 8: логическая ТРИЗ-задача

Какое слово состоит из трёх слогов, но не имеет гласных звуков?

Ответ: _______________________

#### Самооценка и рефлексия

1. Я умею различать гласные и согласные звуки. ⭐⭐⭐
2. Я могу определять количество слогов в слове. ⭐⭐⭐
3. Я знаю, что такое ударение. ⭐⭐⭐
