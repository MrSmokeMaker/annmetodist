# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся, как песня,
Согласные — как стук дождя.
Слог считаем по гласным,
Ударение — где голос сильней.

#### Ловушка для внимательных:
Ловушка: «В слове «крот» два слога».
Почему это не так? Потому что в слове «крот» только один гласный звук, значит, и слог только один.

#### Уровень 1: Старт

Задание 1: образец решения
Распределите звуки на гласные и согласные:
Образец: [а] — гласный, потому что его можно пропеть.
[к] — согласный, потому что он «стучит», как дождь.

Слова: [м], [о], [т], [и], [л], [с].

Задание 2: соедини стрелками
Соедини звуки с их характеристиками:

Звуки: [п], [у], [р], [э], [х], [ы].
Характеристики: гласный, согласный.

Задание 3: раскраска
Раскрась гласные звуки красным, а согласные синим:
Слова: [н], [о], [г], [а], [д], [ш].

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распредели слова по количеству слогов:

| 1 слог | 2 слога | 3 слога |
|--------|---------|---------|
|        |         |         |

Слова для распределения: дом, школа, машина, лес, книга, ракета.

Задание 5: ловушка Незнайки
Незнайка утверждает: «В слове «яблоко» три слога». Найди ошибку Незнайки и запиши правильное объяснение:
Линии для ответа: _______________________

Задание 6: каллиграфическая минутка / прописи
Пропиши элементы букв по образцу:
«Качалочка», «секретик», «крючок до середины строки».
Слоги для прописывания: ма, ко, ту, ре, зи.

#### Уровень 3: Детектив Pro

Задание 7: шифровка
Разгадай зашифрованное слово:
Кодовая таблица: 1=А, 2=Р, 3=Т, 4=И, 5=С
Зашифрованное слово: 4-1-3-2
Разгаданное слово: _______________________

Задание 8: логическая ТРИЗ-задача
Какое слово имеет больше слогов: «олень» или «лошадь»? Объясни свой ответ:
Линии для ответа: _______________________

#### Самооценка и рефлексия
⭐⭐⭐ Оцени свои успехи на занятии:
1. Умею отличать гласные от согласных: ⭐⭐⭐
2. Могу правильно делить слова на слоги: ⭐⭐⭐
3. Знаю, как определить ударение в слове: ⭐⭐⭐
