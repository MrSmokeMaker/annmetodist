### 📄 Лист заданий

#### Главное правило урока:
Гласные тянутся — песенки поют,
Согласные — шаги и шорохи: идут.

#### Ловушка для внимательных:
Многие думают, что буквы «й» и «и» — это одно и то же. Но это не так! «Й» — согласный, а «И» — гласный звук.

#### Уровень 1: Старт

Задание 1: образец выполнения
Напиши, какой звук произносит каждый зверёк: гласный или согласный.
Образец: комар — [з] — согласный, потому что [з] нельзя пропеть.

1. Утка — [у] — ______________________.
2. Бык — [р] — ______________________.
3. Пчела — [ж] — ______________________.
4. Корова — [о] — ______________________.

Задание 2: соедини стрелками
Соедини звуки с их характеристиками:

Звуки: | Характеристики:
--------|----------------
[а] | гласный
[л] | согласный
[у] | гласный
[ш] | согласный
[и] | гласный

Задание 3: раскраска
Раскрась гласные звуки красным, а согласные — синим:

- [м]
- [о]
- [т]
- [ы]

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распредели слова в таблицу:

| Гласные | Согласные |
|---------|-----------|
|         |           |
|         |           |

Слова для распределения: дом, лес, кот, стол, яма, река.

Задание 5: ловушка Незнайки
Незнайка утверждает: «В слове «стол» три слога». Найди ошибку Незнайки и запиши правильное объяснение:

Линии для ответа: __________________________________________________________________

Задание 6: каллиграфическая минутка
Пропиши слоги: ма, му, ми, мо, мы. Обрати внимание на образные элементы букв (по методике Мазиной).

Линии для ответа: __________________________________________________________________

#### Уровень 3: Детектив Pro

Задание 7: шифровка
Разгадай зашифрованное слово:

Кодовая таблица:
1 = А, 2 = Р, 3 = Т, 4 = И, 5 = С

Зашифрованное слово: 4-1-3-2

Разгаданное слово: _______________________

Задание 8: логическая задача
Какое слово содержит больше слогов: «школа» или «парта»? Объясни свой ответ:
