# Лист заданий для печати

#### Главное правило урока:
Гласные тянутся — песенки поют,
Согласные — в гости к ним идут!

#### Ловушка для внимательных:
Некоторые дети думают, что если слово начинается с буквы «й», то этот звук — гласный. На самом деле «й» всегда согласный звук!

#### Уровень 1: Старт

Задание 1: образец решения
Распредели буквы на гласные и согласные:
а) а — гласный;
б) т — согласный.
Теперь распредели самостоятельно:
в) у — ______;
г) к — ______.

Задание 2: соедини стрелками
Соедини буквы с их характеристиками:
| Буквы | Характеристики |
| --- | --- |
| м | гласный |
| о | согласный |
| р | звонкий |
| и | мягкий |

Задание 3: раскраска
Раскрась гласные красным, а согласные синим:
м, а, к, и

#### Уровень 2: Практик

Задание 4: сортировочная таблица
Распредели слова по колонкам:
| Гласные | Согласные |
| --- | --- |
|   |   |
Слова для распределения: дом, лес, мяч, роса, стол, окно.

Задание 5: Ловушка Незнайки
Незнайка утверждает: «В слове «ёжик» три слога». Найди ошибку Незнайки и запиши правильное объяснение:
Линии для ответа: _______________________

Задание 6: каллиграфическая минутка
Пропиши слоги: ма, мо, му, мы, ми

#### Уровень 3: Детектив Pro

Задание 7: шифровка
Разгадай зашифрованное слово:
1 = А, 2 = Р, 3 = Т, 4 = И, 5 = С
Зашифрованное слово: 4-1-3-2
Линии для ответа: _______________________

Задание 8: логическая задача
Какое слово содержит три слога и начинается с гласного звука?
Линии для ответа: _______________________

#### Самооценка и рефлексия
⭐⭐⭐ Оцени свои успехи на занятии:
1. Я умею различать гласные и согласные звуки. ⭐⭐⭐
2. Я знаю, как делить слова на слоги. ⭐⭐⭐
3. Я могу правильно ставить ударение в словах. ⭐⭐⭐
