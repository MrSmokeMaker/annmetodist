# Анализ шаблона практических заданий (activities.json)

> [!NOTE] Этот документ рассматривает структуру JSON, используемую для практических активностей, и описывает внедренные улучшения, делающие шаблон более гибким, поддерживаемым и полезным для педагогов и разработчиков.

---

## 1. Описание структуры

```json
[
  {
    "id": "act_finger_gym",
    "category": "Разминка",
    "title": "Пальчиковая гимнастика",
    "short_description": "Разогрев кистей, снятие гипертонуса пальцев перед работой.",
    "sample_text": "..."
  },
  ...
]
```

| Поле | Назначение | Замечания |
|------|------------|-----------|
| **id** | Уникальный идентификатор (машинный) | Использует префикс `act_`; удобно для стабильных ссылок. |
| **category** | Человекочитаемая группа (например, "Разминка") | Стандартизирована через `categories.json`. |
| **title** | Краткое имя, отображаемое пользователю | Работает отлично, используется в карточках и PDF. |
| **short_description** | Однострочное резюме | Дает быстрый обзор сути приёма. |
| **sample_text** | Подробный скрипт инструкции (часто многострочный) | Сохранен для 100% обратной совместимости. |

## 2. Реализованные расширения

```json
{
  "id": "act_finger_gym",
  "category": "Разминка",
  "title": "Пальчиковая гимнастика",
  "short_description": "Разогрев кистей, снятие гипертонуса пальцев перед работой.",
  "duration_minutes": 5,
  "difficulty": "easy",
  "learning_objectives": [
    "Разогреть мелкие мышцы кистей и фаланги пальцев",
    "Снять мышечное напряжение и гипертонус перед письменной работой"
  ],
  "materials": [
    "Массажные шарики Су-Джок (по желанию)"
  ],
  "steps": [
    {
      "order": 1,
      "title": "Упражнение ‘Замочек’",
      "description": "Сцепление пальцев в замок, мягкие волнообразные движения кистями."
    },
    {
      "order": 2,
      "title": "Упражнение ‘Колечки’",
      "description": "Поочередное касание большого пальца со всеми остальными с ускорением."
    }
  ],
  "assessment": {
    "type": "observation",
    "criteria": [
      "Свободные, ненапряженные движения без скованности",
      "Точное изолированное смыкание пальцев"
    ]
  },
  "tags": ["разминка", "моторика", "кисти"]
}
```

### Пояснение добавленных полей
| Новое поле | Зачем |
|------------|------|
| `duration_minutes` | Позволяет планировать расписание и автоматически рассчитывать время урока. |
| `difficulty` | Помогает учителю подобрать активность под возраст/уровень группы. |
| `learning_objectives` | Согласует задание с учебными целями и стандартами. |
| `materials` | Ясно указывает, что нужно подготовить заранее. |
| `steps` (массив) | Дает готовый к рендерингу список шагов; каждый шаг может ссылаться на медиа‑ресурсы. |
| `assessment` | Предоставляет конкретные критерии оценки выполнения. |
| `tags` | Улучшает поиск и фильтрацию в UI. |
| `metadata` | Позволяет вести журнал изменений, удобно для CI‑проверок. |
| `localizations` | Делает шаблон готовым к многоязычной поддержке. |
