# Pull Request: Улучшение UI и добавление генерации материалов

## 📋 Описание изменений

Этот PR добавляет значительные улучшения пользовательского интерфейса и функциональности приложения "Методист". Основные изменения включают систему генерации учебных материалов с тремя типами контента и улучшенный дизайн.

## 🚀 Основные функции

### 🎨 Улучшения UI/UX:
- **Современный дизайн** с темной темой и акцентными цветами
- **Шрифты Nunito** для лучшей читаемости
- **Плавные анимации** и переходы между состояниями
- **Адаптивный дизайн** для мобильных устройств

### 🔧 Новая функциональность:
1. **Селектор типа генерации** (три варианта):
   - 📝 **Конспект урока** - структурированный план занятия
   - 📋 **Лист заданий** - практические упражнения для учащихся
   - 🏠 **Домашнее задание** - задания для самостоятельной работы

2. **Универсальная кнопка генерации**:
   - Одна кнопка работает для всех трех типов
   - Динамическое обновление текста
   - Индикация состояния загрузки
   - Эмуляция API запросов (2 секунды)

3. **Кнопка "Поделиться"**:
   - Интеграция с Web Share API
   - Fallback для старых браузеров
   - Активация только после генерации материала
   - Копирование в буфер обмена

4. **Система статистики**:
   - Счетчик сгенерированных материалов
   - Анимация count-up при обновлении
   - Локальное хранение состояния

## 📁 Измененные файлы

## ⚠️ Потенциальные проблемы

1. **Web Share API** - поддерживается не во всех браузерах (реализован fallback)
2. **Шрифты Nunito** - необходимо убедиться в корректном отображении
3. **Анимации** - могут быть отключены при `prefers-reduced-motion`
